# 私人模考（加密） / プライベート模試（暗号化）

**中文：** 个人学习用的静态模考网站（ETS 托业 950+ 真题模考第 1 套）。仓库中**只有密文**：题目、听力原文、解析和音频都用 AES-256-GCM 加密（密钥由 PBKDF2-SHA256、600,000 次迭代、随机盐从密码派生），在浏览器中用 WebCrypto 解密。没有密码无法查看任何内容。页面提供 **中文 / 日本語** 界面切换。

**日本語：** 個人学習用の静的模試サイト（ETS TOEIC 950+ 過去問模試 第1回）。リポジトリには**暗号文のみ**があります。問題・スクリプト・解説・音声は AES-256-GCM で暗号化され（鍵は PBKDF2-SHA256・60万回反復・ランダムソルトからパスワード派生）、ブラウザ内の WebCrypto で復号します。パスワードなしでは内容を閲覧できません。UI は **中国語 / 日本語** を切り替えできます。


## 模式 / モード

**中文：**
- **1 小时模式（IP 在线版 · 90 题）** — 公司每月 IP 在线考试形式  
- **2 小时模式（完整版 · 200 题）** — 全真 L&R  
- 另可只练听力或只练阅读  

**日本語：**
- **1時間モード（IPオンライン版 · 90問）** — 企業の毎月 IP オンライン形式  
- **2時間モード（完全版 · 200問）** — 本番形式 L&R  
- リスニングのみ / リーディングのみの練習も可

## 文件说明 / ファイル

| 路径 / パス | 说明 / 説明 |
|---|---|
| `data/meta.json` | KDF 参数和盐（非机密） / KDF パラメータとソルト（機密ではない） |
| `data/t1.bin` | 加密的题目数据 / 暗号化された問題データ |
| `data/a1.bin`–`a4.bin` | 按 Part 加密的听力音频 / Part ごとの暗号化リスニング音声 |
| `audio/soundcheck.mp3` 等 | 音量测试与说明用 TTS（非原书音频） / 音量テスト・指示用 TTS（原書音声ではない） |
